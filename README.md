# Smart Coverage. Real Advice.

The daily insurance podcast from The Jordan Insurance Agency: one real question about Medicare,
Health, Home or Auto per episode, published every day at 9:00 AM Eastern on Apple Podcasts, Spotify
and thejordaninsuranceagency.com/podcast.

| Folder | What's in it |
|---|---|
| `PLAYBOOK.md`, `SKILL.md` | Strategy and the step-by-step skill |
| `references/` | Operating plan, Episode Factory (n8n) guide, compliance, templates |
| `brands/` | Brand rules for the show |
| `assets/` | Cover art, thumbnails, intro and outro music |
| `episodes/`, `bench/` | Episode notes and test scripts |
| `scripts/` | Brand-name check (run before every commit) |
| `studio/` | The Podcast Studio page the team uses to request episodes |

The live production system runs in n8n. Its version history is the source of truth for the
workflows; IDs are in `references/episode-factory.md`.

What changed and when: [`CHANGELOG.md`](CHANGELOG.md).
